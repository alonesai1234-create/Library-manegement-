# Library Management System

Stack: HTML/CSS/JavaScript + Node.js/Express + MySQL.

Setup:
1. Install Node.js and MySQL.
2. Import database/library.sql into MySQL.
3. Copy .env.example to .env and set DB_PASSWORD.
4. Run `npm install` then `npm start`.
5. Open http://localhost:3000.

Default login: admin / admin123

Features: dashboard, book CRUD, member CRUD, search, issue/return, overdue fine calculation, JWT authentication, admin/librarian roles.
